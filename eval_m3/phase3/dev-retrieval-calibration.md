# M3 Phase 3 DEV 相关性校准

仅使用冻结的 `eval_m3/datasets/kb-dev.json`，40 case / 50 原始用户回合。本 worktree 为 Windows CRLF 检出，原始 SHA256 `3387b42534600f0867ba528eef3513ddbeef40ef28a279c264e4cb789559fea6`；规范化 UTF-8 / LF 后 SHA256 `1486e9f227fe84dfd8ec7f62a889a4ef6d09e959e3ad06d05f4784dd14a4a655`，与冻结 manifest 一致。读取当前冻结的 35 篇知识库，95 个标题段；只在固定业务时间的在期文档上统计分数。没有读取 HOLDOUT、没有运行 agent 或 DeepSeek、没有修改问题、gold、语料或 RRF 参数。

本机真实 Ollama `bge-m3` 产生缺失的 50 个查询向量，1024 维；随后用 `--offline` 只读缓存重放，结果在 `dev-retrieval-calibration.json`。后续模型实际工具查询可能改写或补全指代；此报告只描述原问题的静态信号，不是答案准确率或 Phase 5 成绩。

## DEV 分布与候选

17 个回合有 knowledge_base gold，共 35 个精确标题段。无 gold 的动作、规则问题和进度问题不视为检索负样本。另列 9 个诊断负样本：2 个知识库答不了、4 个纯寒暄、2 个无关问题、1 个提示词索取。纯寒暄在产品预拦截后不应进入检索；同一主题的未知事项和提示词索取仍由决策拒答，相关性下限不负责判定知识库是否拥有问题所需事实。

| 信号与粒度 | 候选值 | 对 gold 的影响 | 对无关问题的影响 |
|---|---:|---|---|
| cosine，逐段保留 | >=0.45 | 35 个 gold 段均在候选池；原 hybrid top4 的 19 个精确 gold 命中全部保留 | 两条无关问题均返回空 |
| cosine，逐段保留 | >=0.475 | 35 个 gold 段仍在候选池 | 两条无关问题均返回空 |
| cosine，逐段保留 | >=0.50 | 删除 026 追问的 gold 段 | 两条无关问题均返回空 |
| cosine，整次查询放行 | max>=0.55 | 误拒 026 追问 | 两条无关问题均返回空 |
| BM25，逐段保留 | >=2 | 删除 001 的两个 gold 段，及词法零分的 026 追问 gold | 两条无关问题均返回空 |
| BM25，整次查询放行 | max>=2，放行后仍取 score>0 | 原 BM25 top4 的 19 个精确 gold 命中全部保留；026 追问的裸指代原本就是全零分 | 两条无关问题均返回空 |

Python 的 BM25 原始分数受固定索引的文档频率、长度和查询词影响；`2` 只依据本冻结语料与 DEV 的结果选择，不能换算成余弦 `0.45`，也不是通用置信度。

最低 gold cosine 为 0.490605（026 的追问“按你前面讲的，垫的钱往哪儿报，最多报多少？”）；其 BM25 全零。两个无关问题的最高 cosine 分别 0.393468（快速排序）/ 0.445863（天气），最高 BM25 分别 1.651769 / 1.932819。

001 运费问题的两个指定 gold 段 BM25 为 1.390095 / 1.555252，整次问题最高 BM25 约为 15.27。因此用 `>=2` 删段会丢失事实依据，先以查询最高分判断是否有词法相关主题、放行后仍按正分排序能避免新增这类损失。

## 用户确认的运行时口径

用户已选择 hybrid 用逐段 `cosine>=0.45` 后融合；退回 BM25 时先要求整次查询 `max_score>=2`，再沿用正分排序。没有采用两者都只做整次查询放行的另一候选。信号、阈值、作用粒度、最高分和筛除数量均写入工具 trace；都不称为 confidence。

固定门槛已写入产品检索，等于门槛的分数放行，RRF 的参数及最多 4 段上限均保持。知识库仍只按 effective_from/effective_to 过滤；仍在期的标准规则与活动规则复述不在此模块擅自决胜，资格和优先级由结构化 `catalog.select` 决定。gold 的 doc_id/version 只用于 DEV 校准，绝不成为线上过滤 oracle。

同一 50 回合只读重放同时调用最终产品 `KnowledgeBase.search`，hybrid 与 BM25 的实际结果均逐条匹配上述候选算法。重放前后缓存文件 SHA256 和 mtime 均相同，未写缓存。

原问题 hybrid top4 合计仅命中 19/35 精确 gold 段，001、012、026 追问原本没有精确 gold 段进入 top4，存在相似的其他来源。这一限制属于原有排名及裸指代表达，本阶段没有据此改 rerank、RRF、top_k 或评测标注。此统计不能证明最终对话是否正确；实际工具查询和答案检查留给后续阶段。
